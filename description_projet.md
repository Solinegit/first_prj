L'idée du prjet est de créer un site web (ou application) qui permet de gérer les coupons de réduction.

L'idée est de pouvoir rentrer dans le site les coupons que l'on possède, avec leur date de validité, sur quoi ils sont valables et à quelles conditions.

Ensuite, il y aurait un calendirer où l'ont peut visualiser les coupons sur les jours où ils sont valides.
